# 안전·법률 검토 체크리스트

이 문서는 개발 체크리스트이며 법률 자문이 아닙니다. 한국 출시 전에는 변호사와 개인정보·위치정보 담당자의 검토가 필요합니다.

## 초기 출시 원칙

- 성인 전용 서비스로 운영한다면 국내 적용 기준과 앱스토어 정책에 맞는 성인 확인 절차를 연결합니다.
- 성매매 권유, 조건 만남, 스토킹, 괴롭힘, 사칭, 미성년자 의심, 사진 유포 협박을 신고 사유로 제공합니다.
- 랜덤 익명 채팅과 공개 연락처 게시 기능은 초기 범위에서 제외합니다.
- 신고가 접수되면 관련 대화 ID와 제한된 증거만 별도 보존하고 관리자 검토 큐로 보냅니다.
- 불법 촬영물, 비동의 유포물, 아동·청소년 성착취물 대응 절차와 긴급 차단 절차를 마련합니다.

## 개인정보

- 성별정체성, 성적 지향, 세부 성향은 노출 피해가 큰 정보입니다. 민감정보 수준으로 분리 동의, 최소 수집, 항목별 공개 제어를 적용합니다.
- 탈퇴, 공개 철회, 차단 시 검색·추천·채팅 노출을 함께 중단합니다.
- 개인정보 처리방침에는 수집 목적, 보관 기간, 제3자 제공, 처리 위탁, 삭제 절차를 명확히 적습니다.

## 위치정보

- 초기 버전은 GPS를 수집하지 않고 사용자가 선택한 지역만 사용합니다.
- GPS 주변 탐색을 추가할 때는 위치기반서비스 관련 신고 여부, 위치정보 이용약관, 별도 동의, 철회·일시 중지 기능을 먼저 검토합니다.
- 정확한 좌표나 이동 경로를 상대방에게 제공하지 않습니다.

## 공개 요청 사진

- UI 명칭은 `비밀 사진`보다 `공개 요청 사진`을 우선 사용합니다.
- 상대별 승인, 철회, 만료, 워터마크, 접근 로그를 지원합니다.
- Android 화면 캡처 억제는 적용할 수 있지만 완벽한 DRM으로 표현하지 않습니다.
- iOS 스크린샷과 외부 카메라 촬영은 완전히 차단할 수 없으므로 워터마크와 신고 절차를 함께 둡니다.

## 운영 준비

- 이용약관, 개인정보 처리방침, 커뮤니티 가이드라인 작성
- 신고 처리 책임자와 처리 SLA 지정
- 관리자 접근 권한 최소화와 감사 로그 적용
- 앱스토어 UGC 정책과 데이팅 앱 심사 기준 확인
- 위치 기능 추가 전 위치정보법 검토
